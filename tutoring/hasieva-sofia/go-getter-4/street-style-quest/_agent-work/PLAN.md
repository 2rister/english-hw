# Plan — Street Style Quest

## Goal and non-goals

Build seven 20-25 minute mobile sessions that recycle Unit 1 clothing language,
the learner's new-word list and Use of English. This is not a public class
dashboard and does not transmit audio or personal data.

## Preconditions and authority

The book position and private error categories are verified. The user
authorised GitHub Pages publication in the existing homework repository.

## Stages, files and expected outputs

1. Create a data-driven static app with seven day definitions.
2. Add responsive editorial game UI, progress and badges.
3. Add deterministic checking, adaptive hints and local persistence.
4. Add writing self-check, local microphone recording and summary export.
5. Run content, privacy, persistence and mobile browser tests.
6. Publish only the new route and verify HTTP 200.

## Verification

Syntax checks, content schema checks, no-Cyrillic/public-privacy checks,
Playwright at 390x844, reload persistence, badge threshold and microphone
fallback. Independent content QA may use FreeLLMAPI with only the bounded
content file.

## Executor handoff

Use vanilla HTML/CSS/JS. Keep all learner-visible strings in English. Do not
copy workbook prose or images. Do not commit graph or project-knowledge output.

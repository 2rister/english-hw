# Astra routing record — Street Style Quest

## Deliverable and task type

A seven-day, mobile-first vocabulary and Use of English quest for one A2-B1
learner, hosted on GitHub Pages. Each day must take approximately 20-25
minutes and move from recognition to productive writing and speaking.

## Assigned roles and bounded inputs

- Librarian: verified Go Getter 4 position, SB/WB/TB pages and private error categories.
- Evidence researcher: bounded Consensus literature on gamification, retrieval and vocabulary.
- Planner: seven-day retrieval schedule and mastery rules.
- Executor: static HTML/CSS/JS app only.
- Reviewer: mobile behaviour, learning validity, privacy and persistence.
- Archivist: task record, Learn Core changelog and backlog after verification.

## Dependencies and order

Research and source verification precede planning. Implementation precedes
browser testing. Publication happens only after privacy and mobile checks.

## Acceptance criteria

- Seven distinct daily sessions with visible progress and saved state.
- New vocabulary from the learner's notes plus the verified Unit 1 word set.
- Spelling, vocabulary form and Use of English receive repeated practice.
- Writing and speaking transfer tasks are present.
- Hints appear only after an attempt and become progressively more specific.
- No surname, marks, raw errors, secrets or copyrighted page images are public.
- GitHub Pages returns HTTP 200 and the app works at a phone viewport.

## Authority boundaries

The user authorised local installation and publication to the existing homework
GitHub Pages repository. Audio remains on-device and is never uploaded.

## Stop conditions and unresolved risks

Do not publish if progress persistence, mobile layout or privacy checks fail.
Time estimates are instructional estimates, not enforced timers.

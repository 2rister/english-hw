# Changelog — Хасиева Софья · Go Getter 4 Mini App

## 2026-10-10

- Built the catalog Miso reel, so a tap performs the mascot instead of flickering between two states. All three expression frames now play in sequence — surprise (fully in at 170 ms) → side-eye (500 ms) → wink (840 ms, held 300 ms) — and the release walks the same path back into the study pose over 220 ms. Each expression stays dominant for about 210 ms, and because only one cross-dissolve runs at a time the panel never gaps. The layers are three stacked `<img>` elements owned by WAAPI timelines, so every frame is decoded once, `pointerdown` gives 130 ms of press feedback that always returns to rest, and a tap landing during the release queues instead of restarting. The cat also breathes while idle: about 1% of vertical stretch as a CSS animation on the stage, pivoting on the ground contact so the paws stay planted, tagged off under `prefers-reduced-motion` along with the reel. Tracing layer opacity frame by frame caught a real defect first: the base layer had no keyframe at offset 1, so the browser filled it from the underlying value and the study pose bled back through the reel as a double exposure. New `--ease-out` and `--ease-in-out` tokens are shared by the stylesheet and the JS. Cache key is now `miso-motion-v7-20261010`. Verified with a headless-Chrome screencast, a per-frame opacity trace, and behaviour checks for press, queue and reduced motion; a real iPhone 14 Telegram-WebView receipt is still outstanding.
- Fixed the catalog Miso animation at its source. The mismatch was measured first: the base frame `miso-studying-book-cutout.png` was a *different render* from the three reaction frames — its ginger coat spans 0.71 of the frame height against 0.88–0.92, and its mean lit colour is (93,53,31) against (157–165,103–111,71–80) — so every tap grew the cat ~25 %, shifted it up and relit it, which the `brightness/saturate` CSS hack only masked. The base is now `miso-studying-book.png`, the same render batch as the reactions, and that filter is gone. Each frame ships as an 840px WebP derivative (155–172 KB instead of 1.7–2.0 MB PNG, PNG masters kept as fallback). Frame measurements and the acceptance table are recorded in `street-style-week/assets/mascot/study/ASSET_NOTES.md`.

The focused book-reading Miso now has a colour-aligned base state and an interruptible two-layer reaction: tap → expressive reaction → the same transition played backwards into the study pose. The page uses cache-versioned assets (`miso-catalog-motion-v5-20261010`); JavaScript syntax and diff checks passed. Public browser verification confirmed the current reaction asset loads and cleans up after the return. This is not a real iPhone 14 Telegram-WebView receipt.

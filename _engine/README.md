# Движок домашек

Основная часть больше не пишется заново. Есть шаблон и конфиг; для новой группы меняется только конфиг.

```
_hw-engine/
  template.html      ← механика страницы. НЕ РЕДАКТИРОВАТЬ под конкретную группу
  build.py           ← сборка: конфиг + картинки → готовая страница
  groups/7-3/
    config.json      ← всё, что своё у группы
    img/*.jpg        ← картинки, 480px, качество 48
```

## Новая группа на том же материале

```bash
cp -r groups/7-3 groups/8-5
```
В `groups/8-5/config.json` поменять три поля — `group`, `students`, `unit` — и пересобрать. Всё остальное останется.

## Сборка

```bash
python3 build.py groups/8-5/config.json --mode pages
```

Режимы картинок:

| Режим | Что делает | Когда |
|---|---|---|
| `pages` | ссылки `img/имя.jpg` рядом со страницей | GitHub Pages — по умолчанию |
| `offline` | картинки вшиты в файл (≈1 МБ) | отправить файлом, работает без интернета |
| `remote` | абсолютные URL из `images_remote` | если картинки лежат на CDN |

## Поля конфига

| Поле | Смысл |
|---|---|
| `unit` | ключ юнита на сервере (`u1`, `u10`, `u1p`…). Под новый юнит завести ключ в `Code.js` |
| `group` | номер группы, попадает в заголовок отчёта |
| `students` | список имён в порядке кнопок |
| `title` / `titleAccent` | заголовок на первом экране, вторая часть цветная |
| `subtitle` | строка под заголовком |
| `reportTitle` | первая строка отчёта учителю |
| `labels` | подписи экранов: `mc`, `prep`, `prepShort` |
| `intros` | 4 заставки перед блоками: `{t, d}` |
| `mc` | картинка + варианты: `{img, a, f, o[]}` |
| `sp` | написание по буквам: `{img, pre, w, x}` — `x` это две лишние буквы |
| `pairs` | пары `[слово, определение]` |
| `ty` | вписать слово: `{s, h, a, img?}` |
| `prep` | выбор из вариантов: `{s, a, o[], f}` |
| `images` | псевдоним → имя файла (`cover`, `hero` и любые переопределения) |
| `mission` | устное задание целиком, блоки рендерятся по типу поля: `check` / `ol` / `phrases` / `model` / просто `p` |

## Обязательно

- Тестовый прогон называть `ПРОВЕРКА …` — такие строки уходят во вкладку ТЕСТЫ, а не в группу.
- Под новый юнит завести ключ в `Code.js` (`UNITS`) и задеплоить, иначе сервер проверит ответы по чужим ключам.
- Объём считать по `Стандарт домашки и Level up.md`: 15 минут по самому быстрому ученику.
